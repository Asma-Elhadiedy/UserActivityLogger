# Support policy

This document describes the available support channels for UserActivityLogger.

## Support channels

- Documentation: Consult the [README](README.md) and guides in `docs/` for installation, architecture, and configuration questions.
- GitHub Discussions: Use [Discussions](https://github.com/Asma-Elhadiedy/UserActivityLogger/discussions) for general questions, troubleshooting, and design inquiries.
- GitHub Issues: Use [Issues](https://github.com/Asma-Elhadiedy/UserActivityLogger/issues) to report confirmed bugs or submit concrete feature proposals.
- Security vulnerabilities: Refer to the [Security policy](SECURITY.md) for confidential disclosure instructions. Do not use public issues.

UserActivityLogger is maintained on a volunteer basis without a commercial service-level agreement.
